# Movie AI App

An intelligent movie application powered by AI, built with Vite and modern web technologies.

## About

Movie AI App is a web application that leverages artificial intelligence to provide movie recommendations, information, and insights. The application is built using Vite for fast development and optimized production builds.

## Tech Stack

- **Frontend:** JavaScript (85.3%), CSS (12.7%), HTML (2%)
- **Build Tool:** Vite
- **Language:** JavaScript

## Getting Started

### Prerequisites
- Node.js (v14 or higher)
- npm or yarn package manager

### Installation

Install the dependencies:

```bash
npm install
# or
yarn install
```

### Development

Run the development server:

```bash
npm start
# or
yarn start
```

The application will be available at `http://localhost:5173` (or the port shown in your terminal).

## Build for Production

```bash
npm run build
# or
yarn build
```
